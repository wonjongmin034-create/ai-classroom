⚙️ 관리

자료·도구·프롬프트를 여기서 직접 추가하고 지울 수 있어요. 저장하면 1~2분 뒤 사이트에 반영돼요.

1. 연결하기

저장하려면 GitHub 접근 토큰이 필요해요. 토큰은 이 브라우저에만 저장되고, 다른 곳으로 보내지 않아요. 공용 PC에서는 쓰지 마세요.

토큰 만드는 방법 (처음 한 번만)
  1. GitHub에 로그인한 뒤 토큰 만들기 화면 ↗을 엽니다.
  2. Token name은 ai-classroom 관리, Expiration은 90일 또는 1년을 고릅니다.
  3. Repository access에서 Only select repositories를 고르고 ai-classroom 하나만 선택합니다.
  4. Permissions → Repository permissions에서 Contents를 Read and write로 바꿉니다.
  5. 맨 아래 Generate token을 누르고, 나온 github_pat_... 문자열을 복사해 아래에 붙여넣습니다.
